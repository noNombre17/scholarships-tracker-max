## Scam / dead-program warnings

- `meritscholarship.org` is **dead** — National Merit is now `nationalmerit.org`.
- **Concurrent Challenge Scholarship repealed** → replaced by ACCESS to Acceleration.
- **Governor's Distinguished Scholarship renamed** → Governor's Scholars Program.
- **Razorback Foundation** = athletics fundraising, NOT a student scholarship application.
- **Pinnacle Bank Foundation** → bank rebranded to Vallant; no published student program — verify before citing.
- `arkansashigher.edu` / `adhe.arkansas.gov` are dead; official = **adhe.edu**, **sams.adhe.edu**.
- Legitimate scholarships never charge application fees. Red flags: pay-to-apply, "guaranteed" awards, bank info before interview, required purchase.
- Doodle for Google page was unreachable at research time — verify 2026–27 cycle before investing time.
- Data-privacy note: Appily is a self-declared data broker; Unigo discloses selling personal info — use a throwaway email if concerned.
